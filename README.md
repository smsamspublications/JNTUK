# JNTUK R23 - Flutter Lab

Lab experiments for the Flutter laboratory, B.Tech V Semester, Department of Artificial Intelligence & Data Science, LBRCE (JNTUK R23 Regulation).

- `JNTUK_R23_Flutter_Lab_Experiments/` - Experiments 1-10 as Android Studio projects:
  - `all_in_one/flutter_lab_all` - one project with every experiment as its own file
  - `separate/exp01 ... exp10` - one project per experiment
  - `setup_all.sh` (macOS/Linux) and `setup_all.bat` (Windows) - run once to add the Android platform folder
  - See the README inside that folder for step-by-step setup.
